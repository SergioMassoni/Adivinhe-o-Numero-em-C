# Jogo de Adivinhação em C

Programa desenvolvido em linguagem C como exercício de lógica de programação.

## Sobre o projeto

O programa sorteia um número de 1 a 5 e desafia o jogador a adivinhá-lo. O jogador possui **3 tentativas** e recebe uma dica informando se o palpite é maior ou menor que o número sorteado.

Ao final da rodada, o programa informa o resultado e permite iniciar uma nova partida.

## Funcionalidades

- Sorteio aleatório de um número entre 1 e 5;
- Limite de 3 tentativas por rodada;
- Dicas para orientar o jogador;
- Mensagem de vitória ou encerramento das tentativas;
- Opção para jogar novamente.

## Como executar

### Pré-requisito

É necessário ter um compilador C instalado, como o GCC.

### Execução

No Windows:

```bash
adivinharnumero.exe
```

No Linux ou macOS:

```bash
./adivinharnumero
```

## Tecnologias utilizadas

- Linguagem C;
- Biblioteca `stdio.h`;
- Biblioteca `stdlib.h`;
- Biblioteca `time.h`.
